| 滥觞 / làn shāng | 起源、发端 | 本义是江河源头水浅，只能浮起酒杯（觞＝酒杯）。＝起始，不是"泛滥" |

| 甚嚣尘上 | 议论纷纷；气焰嚣张 | **多含贬义**，不是"热闹" |

## 附录 ｜ 二、补充词 · 数量 / 程度 / 态度 常出现在干扰项的"程度修饰"里
| 词 | 释义 | 阅读提示 / 同义替换方向 |
|---|---|---|
| 俯拾皆是 / 不胜枚举 | 到处都有，容易得到／多得举不完 | ＝**数量极多**（两词可换用，都表"多"） |
| 寥寥无几 / 凤毛麟角 | 非常少，没有几个／稀少而珍贵 | ＝**数量极少**。凤毛麟角带"珍贵"义 |
| 微乎其微 | 非常小或非常少 | ＝程度极小。注意与"微不足道"（不值得说）区分 |
| 举足轻重 / 无足轻重 | 地位重要，影响全局／无关紧要 | **一对反义**，常被用来设置正反干扰项 |
| 相形见绌 | 相比之下显得不足 | 绌＝不足。**需要"对比"才成立** |
| 捉襟见肘 | 处境困难，应付不过来 | ＝顾此失彼。**是"能力/资源不足"，不是"衣服破"** |
| 不置可否 | 不表明态度 | ＝**没表态**。注意与"莫衷一是"（没得出结论）区分 |
| 讳莫如深 | 把事情真相隐瞒得很深 | ＝**故意不说**，不是"不懂" |
| 同日而语 | 相提并论（多用于否定） | "不可同日而语"＝**差距悬殊，不能比** |
| 一蹴而就 | 一下子就能成功 | **几乎只用于否定**："不可能一蹴而就"＝需要长期过程 |

## 附录 ｜ 三、易混对照 ★ 高危区：这几个词每年都在坑人
| 这一对 / 这一个 | 差别在哪 |
|---|---|
| 不以为然　vs　不以为意 | **然＝对**：不认为是对的 → **反对**； / **意＝心上**：不放在心上 → **不在意**。两个意思完全不同 |
| 不负众望　vs　不孚众望 | **负＝辜负／承受**：没辜负期望 → **褒义**； / **孚＝使人信服**：不能让人信服 → **贬义** |
| 首当其冲 | ＝**最先受到冲击／遭受灾难**。**不是"首先"**，不是"带头做" |
| 望其项背 | 本义＝赶得上。**几乎只用于否定**："难以望其项背"＝**赶不上** |
| 空穴来风 | 本义＝有了洞才有风 → **消息并非毫无根据**。 / （现实中常被误用为"毫无根据"——**看题目语境判断，以题意为准**） |
| 无可厚非　vs　无可非议 | **厚非＝过分指责**：有缺点但可理解 → **不完全对，但不必苛责**； / **非议＝指责**：没什么可指责的 → **完全正确** |
