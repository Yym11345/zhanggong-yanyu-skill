## 二、铁律

1. **每次改卡片必须跑 `repaginate.py`**——不重排就会出现 section 溢出、页码锚点错位。
2. **PDF 页数必须 == HTML 页数**——这是重排成功的判据。
3. **改卡片前先备份**到 `.workbuddy/backup/`。
4. **答案必须多源交叉核验**（华图/上岸鸭/高途/东汇达/星光公考），无可靠信源标「†待核」，**不硬写答案**。
5. **改完必须重跑 `extract_card.py`**——否则 `references/00-17` 与卡片脱节。
6. **不越界（用户 2026-10-30 明确指令）**：卡片只收**言语理解与表达**内容。
   判断推理（图形／定义／类比／逻辑）、数量关系、资料分析的条目**一律不得入卡**。
   这些模块要沉淀，另建独立速记卡 + 独立 skill，与本卡片完全隔离。

## 三、标准改动流程

```
1. 备份   cp 中心理解_方法速记卡.html .workbuddy/backup/卡片_改前_$(date +%Y%m%d_%H%M%S).html
2. 编辑   追加例题 / 修订判定 / 补方法条目
3. 刷新   python scripts/extract_card.py      → references/00-17
4. 重排   python scripts/repaginate.py        → 分页重建 + 页码锚点回写 + PDF 验页数
5. 校验   python scripts/verify_card.py       → 答案表 + 页数一致 + 标签配平 + 存疑扫描
6. 汇报   说明改了什么 + 新页数
```

### 三脚本职责

| 脚本 | 作用 | 注意 |
|---|---|---|
| `extract_card.py` | 卡片 HTML → `references/*.md` | 分类规则**窄规则优先**（先命中题型编号前缀，避免被通用关键词劫持）；页码锚点须还原为「参见〈章节名〉」而非丢弃（丢弃会产生悬空引用） |
| `repaginate.py` | 测量 → 装箱 → 重建 → 回写页码锚点 → PDF 验页数 | **浏览器依赖**：优先 Playwright `chrome-headless-shell`（必须 `--no-sandbox`），回退 Edge |
| `verify_card.py` | 抽答案表 + 页数一致 + 标签配平 + 存疑扫描 | 退出码 1 = 有问题 |

## 四、卡片 HTML 结构速查

```html
<div class="sheet">                    <!-- 一页容器 -->
  <div class="masthead">…</div>
  <section>                            <!-- 一个知识节 -->
    <h2>标题 <span class="tag">副标</span></h2>
    <span id="a-anchor"></span>        <!-- 锚点，交叉引用用（比页码稳定） -->
    <table>…</table>
    <div class="note">…</div>          <!-- 提示框 -->
  </section>
  <div class="foot">…</div>
</div>
```

- 页码由脚本回写：`<span class="pr" data-t="锚点名">N</span>`——**不要手写**，会被覆盖。
- 交叉引用用 `data-t` 指向锚点，**不要写死页码**（重排后会漂移）。

## 五、常见坑（都是踩过的）

| 坑 | 症状 | 解法 |
|---|---|---|
| **Edge `--dump-dom` 静默失败** | 测量报"未取到标记"，0 字节输出 | 用 Playwright `chrome-headless-shell` + `--no-sandbox` |
| **section 缩进未匹配** | 部分 section 没被重排 | 正则兼容 `\n\s*(<section>.*?</section>)` |
| **`<code>` 里的真标签被当 HTML 解析** | 结构错乱 | 检查 `<code>` 内是否含 `<section>` 等标签 |
| **中文引号导致锚点失效** | 目录跳转失灵 | 锚点只用 ASCII |
| **改卡片忘了重排** | 打印时 section 跨页断裂 | 铁律 1 |
| **方法只沉淀在对话里没入卡** | 知识库检索不到 | **每次沉淀新方法，必须同时写回卡片** |

## 六、答案核验纪律（血泪教训）

卡片例题速查表**曾多次出现答案误录**，已发现并修正 3 处：

| 例题 | 原误记 | 现答案 | 性质 |
|---|---|---|---|
| 例3 / 2022 福建 · 柔性电子 | B | **A**（显示／大有可为） | 直观误录 |
| 例14 / 2020 国考 · 测谎仪 | C | **B** | 直观误录 |
| 例28 / 2025 内蒙古 · 生命教育 | B | **D**（敬畏感） | **联想型误录**——判定理由看似自洽，实则错误 |

> 例28 属最危险的一类：判定写得通、逻辑自洽，但答案是错的。**通读发现不了，必须外部交叉核验。**

修正后统一在判定栏标注「★原误记 X，已修正」。

`verify_card.py` 当前可导出 **142 条**例题答案清单供逐条核验，并自动标出含「待核／疑似」等存疑词的条目。
