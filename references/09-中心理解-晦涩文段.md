## (八) 思维提升② ｜ 两者关系 重视多者之间的关系（特别是二者）
| 提升①（高频词） | 提升②（两者关系） |
|---|---|
| 解决"**主体是什么**" | 解决"**主体之间是什么关系**" |
> **晦涩文段读不懂？先数"有几个主体"，再看"它们是什么关系"。** /
> **选项判定三问：**① **主体带全了吗？**（只带一个主体 → 缺关系 → 排除）② **关系方向对吗？**（"依赖光"写成"不依赖"、关系对换 → 排除）③ **主体被偷换了吗？**（"莲子心"变"莲子" → 排除）。

| 例3 / 2023 四川 / 莲子心 | C | 主体：**莲子心**（3 次）、叶绿素、LPOR、DPOR、光。 /   **关系：**被子植物用 LPOR（**唯一需要光**）；一些裸子植物和微生物用 DPOR（**不依赖光**）；**莲子心不存在 DPOR、只有两个 LPOR** → **莲子心的叶绿素合成需要光**。 /   C"**莲子心**的叶绿素合成**需要光**参与"＝主体＋关系＋对象全带 ✓ /   A"叶绿素的形成有两种不同的模式"＝只讲模式，**丢了主体"莲子心"**；**B"裸子植物依赖光"＝关系方向反了**（原文是"不依赖光"）；**D"莲子"有"裸子植物的"两个编码基因＝主体偷换（莲子心→莲子）＋张冠李戴**（两个 LPOR 不是裸子植物的）。 |
| 例4 / 2023 浙江 / Cas9 与 PAM | D | 主体：**Cas9**（3 次）、**PAM 识别序列**（2 次）、水稻（1 次）。 /   **关系：**Cas9 基因组编辑需要识别 PAM（NGG 序列）；**PAM 的存在极大限制了 Cas9 的打靶序列选择**。 /   D"**PAM 识别序列**对**Cas9 基因组编辑**时的影响"＝**两个主体 ＋ 关系方向全带** ✓ /   A"PAM 的**特点和作用**"＝只有 PAM 一个主体，丢了 Cas9；B"**Cas9** 基因编辑方法的特殊性"＝只有 Cas9，丢了 PAM；**C"Cas9 对水稻"＝关系换对**（原文是 PAM→Cas9）。 /   **★ 三个干扰项的死法正好三全：丢一个主体／丢另一个主体／关系换对。** |
> **★ "二者关系"的两种典型表述：** /
> · "**A 需要 B**"（例3：莲子心 需要光） /
> · "**A 对 B 的影响**"（例4：PAM 对 Cas9） /
> **晦涩文段看到这类句式，主体和关系一起抓——正确答案必须把两个主体和关系方向全部带全。**
