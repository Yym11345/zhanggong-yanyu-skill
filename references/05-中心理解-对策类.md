## (五) 对策类文段 · 知识树 ｜ 4 考点 + 5 思维提升 一页全貌
### 考点回顾（4 个）
| ① | **必考点**：凡表达"意思＝对策"的文段都是对策类文段。 |
|---|---|
| ② | **必要条件**：只有…才…；只有才中间更重要；**表达思想和对策是一回事**。 |
| ③ | **理论要点**：必要条件/对策是重点；对策类文段选项优选对策，其重要性 > 问题、意义效果、解释、原因。 |
| ④ | **四种出场**（权威清单见对策专节"实操提醒"）：1. **直接对策**；2. **标志词引导**（**最高频**）；3. **反面提**对策 → 反推；4. **只提问题** → 优选针对性对策；选项无好对策 → 退选「问题」。 |
### 思维提升（5 条）
| ① | **内容 > 形式**：选提及对策内容本身的选项（不是选含"需要"标志词的）；若内容都存在，再考虑形式。 |
|---|---|
| ② | **对策 + 对象**：主题词 = 对策（做什么）+ 对象（谁去做／为了谁做）。 |
| ③ | **宏观 vs 具体**：多层对策时选**最后那个最具体的**（经验 · 有反例，详见提升③）。情况 1（宏观＋并列具体展开）选最后；情况 2（宏观＋后文展开）：看后文信号（"比如"→中心在句 1；"重点／关键"→ 重点在后文；都没→ 结合文段和选项判断）。 |
| ④ | **什么时候不选对策**：1. 文段不是对策类（既无问题也无对策）；2. 文段提了问题，但选项中没有好对策 → 不选对策，退而求其次。 |
| ⑤ | **对策和问题的相关性（一体两面）**：根据问题可以反推对策，**表达思想和对策是一回事**。 |
> **底层一句话（(五) 节总纲）**：**"表达思想和对策是一回事"** → 这条贯穿考点②、思维提升⑤、整体定位——可作为遇到对策类文段时的**第一反应**。

## (五) 对策类文段 ｜ 公考言语必考点 对策 ＝ 必要条件 ＝ 重点
| 考点 | 课件原话 | 展开与做法 |
|---|---|---|
| ① | 对策类文段是**公考言语的必考点**。凡表达"表达意思＝对策"或"所提对策是一回事"的文段都是。 | 必出现**必要条件**句式：只有…才…／必须…／应该…／需要…。 |
| ② | **只有…才…**（必要条件句式）的逻辑链：付出是回报的必要条件 ＝ 只有付出才能有回报 ＝ 想有回报**应该**付出。 | 重点始终是"必要动作"（付出），不是"收益结果"（回报）。 / **关注动作里那个限定语：**付出=必要动作；回报=结果。 |
| ③ | 必要条件／对策是重点，**对策类文段选项优选对策**，其重要性 > 问题、意义效果、解释、原因… | 优选顺序表： / 1. 对策（应该／需要／加强…）─**最优先** / 2. 问题（针对"主要问题"提问时适用） / 3. 意义效果（次选） / 4. 解释／原因（一般不作答案） / ★但意义效果也能作答案 —— 某些"意在说明"型题的落点就是意义效果 |
> **实操提醒：**对策类文段选项里，优先挑带"对策味"（应该／必须／需要／加强／推进／实施）的。选项里有对策就选对策，没有再考虑意义效果。问题类选项仅在问"针对的主要问题"时用。 /
> **★对策标志词同义词表（"亟待"等强语气词按表）：**
> 亟待 ＝ 迫切需要 ＝ 亟须 ＝ 亟需 ＝ 必须 ＝ 应该 ＝ 应当 ＝ 需要。
> **一律当对策标志词处理**，看后面跟着的**动作**。**读音**：**jí dài**（去声去声）。 /
>
> 1. **直接对策**：文段里出现「应该／必须／需要」提出的动作（例 3.4）。 /
> 2. **对策标志词引导**："需要采取／应该采取／我们亟需……"后才是动作（**最高频**）。 /
> 3. **文段反面提对策**：只提错误做法（反面论证）→ 需反推对策。 /
> 4. ★**只提问题不答对策**：文段含消极表述（挑战／瓶颈／威胁／难题／不足／缺陷／风险）→ **优选有针对性、能解决问题的对策**；若选项没有对策，则退而求其次选「问题」。 /
> 例：人民群众的财产性收入偏弱，影响消费能力 → 答案 A. 增加人民群众财产性收入。B 表述问题（类型②）；C 偷换主体（财产性→劳动性）；D "仅从立法"缩小范围无中生有。 /

## (五) 思维提升①② ｜ 内容>形式 · 对策＝形式＋内容
| 总公式 | 拆解 |
|---|---|
| 对策 ＝ 形式 ＋ 内容 | **形式**＝形式词（应该／必须／需要／亟待／亟须／亟需／应当／有必要，等价表见对策考点节）——只表态「要做」、**0 动作信息**（空快递单）；只有形式词 → **伪对策**。 / **内容**＝该怎么做＝动词串（四种形态见下表）——**考点永远落在内容上**。 |
| 内容 ＝ 动作 ＋ 对象 / （＋方式／限定） | **动作**＝动词＋实义宾语，两种伪装：① 抽象占位（挖掘／融合／利用／体现／展示＋抽象名词，如"挖掘共鸣"）② 偷换动作结构（"从 A 到 B 的转变"压成"A 的 B 路径"）→ 一问「它告诉读者怎么做了吗」。 / **对象**＝对谁做／为谁做（名词）。 |
| 生活例 | "这扇门坏了，应该换一把锁"→ 对象＝门、动作＝换、内容＝换一把锁、形式＝应该、对策＝整句。 |
### 提升① ｜ 内容 > 形式（先筛内容，再比形式）
| 判定顺序 | 先用**内容**筛掉伪对策 → 剩下的都有真内容 → **再比形式**。 |
|---|---|
| 伪对策 | 形式含对策词，内容仅"重要性／态度"，无具体动作／对象。 |
| 真对策 | 不一定含对策词，但有**具体动作（加强／推进／建立）或动作对象、范围／方式**。 |
| 课例 | 「考试很重要，**应该**加倍努力」：A"我们应该加倍努力"＝重复原话；C"加倍努力很重要"＝同义重复；**B 胜出（内容更实）**。 |
| 对应关系 | 本课是"□内容"型伪对策；第三步类型①「无关对策」是"□内容且□形式"型干扰项。 |
### 提升② ｜ 主题词 ＝ 对策（做什么）＋ 对象（对谁做）
| 三个考点 | ① 脱动作（只有主题词、无动词）② 脱对象（主题词变／错）③ 对象与动作错位。 |
|---|---|
| 实操三提问 | ① 动词是什么 ② 对象是谁 ③ 二者对应吗——任一不通过 → 立即划掉。 |
### 「内容」的四种形态
| 1. 动作 | 建立／加强／推进／实施／完善 |
|---|---|
| 2. 动作＋对象 | 建立监测平台／完善法律体系 |
| 3. 方式／范围／路径 | 从制度层面／在 XX 范围内／通过 XX 渠道 |
| 4. 对象＋动作＋限定 | 为 XX 建立 XX／对 XX 加强 XX |
经验 · 有反例
一键判断法／词串长度： 拿选项写「应该＋X」，看词串是否重复／空洞—— 词串越长（动作＋对象＋方式＋范围）越像真对策 ：「挖掘」＜「挖掘资源」＜「挖掘民族文化资源」。词串过短多为伪对策。
> **★「老话题＋对策」是高频答型（经验 · 有反例）：**开头话题＋后文对策 ＝ 几乎所有对策题的结构。判据：后文的**对象**换了吗？没换（最常见是换成对策角度）→ 老话题仍重要。答型＝**回扣开头的话题＋对策动作**。例：2022 四川（学术争议→正确态度与方法）／2025 江苏青铜器（青铜研究→亟待深入研究）／2024 山西（数字经济→法律体系协同）。联动：新老话题三种情况（参见〈专题 ｜ 思维提升②的完整答案：新老话题的三种情况 "首句有提示作用"与"新话题重要"不矛盾〉）。 /
> **对策标准句式三层：**上层＝面临问题／背景 → 中层＝**需要采取什么（标志词层，重要标志）** → 下层＝需要做什么。 /
> **七种关系 vs 出场方式：**七种关系是「哪里是重点」的排序依据；四种出场是「怎么选答案」的优选依据——合起来指向"问题 → 标志词 → 动作"。

## (五) 关联词补表 ｜ 为此 · 真伪动作高级形态
> **★关联词补表：因果复句结尾的"承接词"。** /
> **为此**（wéi cǐ）／ 鉴于此 ／ 基于此 ＝「由于这件事／由于这一原因」＝「为了这一目的」→ **回指前文、推出后文**。 /
> 区别于「因为」「因此」「所以」——后者独立使用；前者是**承接词**，不能独立成句。 /
> ★**看到"为此"两字的三动作：**① 往前看一句（题干／背景／原因）② 认是什么功能（多为**问题／原因**）③ 往后看一句（**对策／结果**，重点）。 /
> 例（2025 广西·文博展陈）：提出问题"很难满足海量游人需求" → **为此** → 提出对策"善用人工智能、虚拟现实……"。答案 A「拓展多空间＝善用」调整一下其他三个（挖掘共鸣／融合媒体／利用新视角）都仅态度词、无动作 → 伪对策。 /
> **★伪动作高级形态：偷换动作结构（双向过程变单向描述）。** /
> 例（2024宁夏·智慧治理）：中心句"从智能技术赋能**到**技术融合**的转变**"含两个动作（赋能→融合）。C 项"智能技术赋能**的**智慧治理路径"被压缩为单向修饰 + 名词化"路径" → **偷换了"转变"这个核心动作**。 /
> 判断口诀：拿选项，问"它告诉读者**怎么转变／怎么实现**了吗"。没有 → 伪动作。 /
> **★真动作 vs 伪动作高级形态表：** /
> 动词抽象占位：挖掘／融合／利用／体现／展示 —— 后面只接一个抽象名词 = 伪动作。 /
> 偷换动作结构：含主题词，但把"从 A 到 B 的转变"压缩成"A 的 B 路径"，丢掉核心动词。 /
> 真动作：动作 + 对象 + 方式／路径 / 限定语（连续词串，如"以多模式拓展多空间"）。 /

## (五) ｜ 思维提升 ③④⑤ 多层对策 · 不选对策 · 一体两面
| 提升③ 多层对策 | 后文信号 → 处理 |
|---|---|
| 情况一 / 宏观＋并列分述 | **选最后那个最具体的**（它把宏观对策"具体化"了）。经验 · 有反例 / 例（2023 国考·适老化改造）：宏观"提升思想认识"＋并列分述（宣传引导／服务中心／转变观念）→ 答案 D「加强宣传引导，做到'心理无障碍'」。 |
| 情况二① / 后文有"比如／例如" | 类似观点＋解释说明 → **中心在句 1**。 / 例（2023 广东·烈士纪念设施）："比如"扫码／VR → 答案 C"如何强化教育作用"；B 偷换"建设管理好"；D 偷换落点。 |
| 情况二② / 后文有"重点／关键在于" | 层层递进 → **重点在后文**。 |
| 情况二③ / 既无举例也无重点词 | 结合文段和选项判断（出题人不会同时出对应前后的两选项）。 / 例（2023 湖北·质检报告）→ 答案 D"让质检报告经得起质检"＝主题词＋动作。 |
| 适用边界 | ①② 解决"看到一条对策时怎么选"，③ 解决"看到好几条对策时怎么选"。 |
| 提升④ 什么时候不选对策 | 规则与例证 |
|---|---|
| 1. 文段不是对策类 | 既没有问题也没有对策 → 选作者观点／评价／意义，**不选对策**。 |
| 2. 有问题、无好对策 | 选项中没有针对性对策 → 退而选"问题描述"或"问题＋虚动作（补短板／有待／需要）"。 / 例（2024 重庆·新农人）：全文仅提问题 → 答案 B"需补短板，否则创业难成"；A 模糊、D 口号召句。 / 反例（2024 黑龙江·知识产权）：只提问题，但 D 给出三个动作的**真对策** → **仍选对策**。 |
| 与前三的关系 | ①②③ ＝「默认有真对策时」怎么选；④ ＝「文段或选项里没对策时」怎么办。 |
| 提升⑤ 一体两面 | 判断规则 |
|---|---|
| 底层一句话 | 对策与问题不是两个独立概念，是**同一件事的两面**（饿了→要吃饭；生病了→要治病）。 |
| ① 问题＋对策 | → 选**对策**。 |
| ② 问题、没对策 | → 选**问题**（见提升④）。 |
| ③ 疑问＋后文作答 | → 选**答案**。例（2024 国考·个人信息保护）：句 2 问"能否连带追究"，句 3 答"可以" → B"应当依法追究下游违法者赔偿责任"。 |
> **一句判断：**看到"应该／必须／需要"先问"它告诉你怎么做吗"——没说动作＝伪动作；文段根本没对策 → 不选对策（提升④）。
