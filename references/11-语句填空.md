## 三、语句填空题 ｜ 考点回顾 新题型 · 看话题衔接
> **题量**：2 题左右。　**问法**："填入画横线部分最恰当的一项是……" /
> **理论要点：话题一致、衔接得当。**
>
>
> | 横线形态 | 重点看 |
|---|---|
| （1）横线为**分句** | 优先注重**句内**话题衔接 |
| （2）横线为**完整语句** | 注重**句子之间**的话题关联 |
### ③ 三种情况（按横线位置分）
| 位置 | 功能 | 说明与例 |
|---|---|---|
| （一）横线在**结尾** | ① **总结前文** / ② **提出对策** | 例："好的成绩需要好的心态…好的睡眠。" |
| （二）横线在**开头** | ① **概括后文** / ② **话题引入** | 例："____。但是我怕闹肚子，犹豫再三，我喝了一杯白开水。"（A 今天天气真好／B 我想喝一杯奶茶） |
| （三）横线在**中间** | 注意与上下文的联系；**把握好主题词**，保证文段话题的一致性 | **最高频**，也是本节重点（见思维提升②） |

## 三、语句填空 · 思维提升① 语感陷阱，不要跳文段
> **陷阱所在：**横线处往往**读起来"很顺"**，凭语感一选就中招——**必须先读完整个文段**再判断。 /
> **判断动作：**横线是**分句**→ 先看**句内**衔接（前后半句是否同一话题）；横线是**完整语句**→ 先看**句子之间**的话题关联。
| 例题 | 答案 | 结构 · 考点 |
|---|---|---|
| 例1 / 2023 广东 / 农村生态文明 | B | ①**【提出观点】**农村生态文明建设，____。　②**【解释】**一是必须加速由高耗能高污染的粗放型农业向清洁循环的集约型农业转变…二是促进农业资源循环利用… /   **横线在中间 → 承上启下；后文"一是…二是…"两条并列，都在讲"绿色循环"**。 /   B"**必须大力推进绿色循环农业发展**"＝概括后文两条 ✓ /   A"必须与**美丽乡村**建设紧密结合"——后文未提美丽乡村；C"必须充分利用**科技研发**"——只对应"一是"里的一个细节；D"必须树立'绿水青山就是金山银山'的**价值导向**"——是对策方向，非后文内容。 |

## 三、语句填空 · 思维提升② 横线在中间：承上启下
> **优先级：承上启下（最优）　＞　侧重承上（次选）　＞　侧重启下（次选）** /
> **为什么"承上启下"最优？**因为**同时满足两个方向的衔接**——它天然是"话题的转折枢纽"。 /
> **动作：**把横线前后各读一句，判断横线是"两端都接"还是"只接一头"。
| 例题 | 答案 | 结构 · 考点 |
|---|---|---|
| 例2 / 2024 辽宁 / 钻石雨 / 正确率 62% | B | ①地上水循环 → 下雨属于**物理变化**　②____　③星球雷电分解甲烷 → 钻石雨属于**化学变化**。 /   B"下'钻石雨'和地球上空下雨**在本质上不同**"＝**承上**（物理变化）＋**启下**（化学变化）✓ /   A"想在地球上见到'钻石雨'是不可能的"——后文没有讨论"能否见到" ✗ |
| 例3 / 2023 国考 / 立案登记制 / 正确率 50% | A | ①"有案必立"仅指**符合法定立案条件**的案件 → 所以____　②**【质疑】**"设立立案标准＝设置门槛，难以保障诉权"　③**【回答】**任何权利都有限度，只有符合标准才能实现。 /   A"推行立案登记制**并不意味着"是案就立"**"＝**承上**（"有案必立"有条件）＋**启下**（引出"对此"的质疑）✓ /   B"不能将'立案难'与司法公正简单关联"——话题偏；C"明确立案标准才能保障合法权益"——与"质疑"方向相反（质疑是**质疑**标准，A 是**先立论**再被质疑）；D"司法资源作为公共产品的有限性"——尾句才出现，太后 ✗ |
| 例4 / 2024 山东 / 工业品下乡 | B | ①**【背景】**高品质工业品从"稀罕物"变"必需品"　②**【提出观点】**工业品下乡不意味着"积压品下乡"，不能拿质次价廉商品糊弄消费者，____　③**【举例论证】**重设计洗衣机外壳（解决生锈）、推宽电压冰箱　④**【观点】**惠民生、增福祉是政策初衷。 /   B"**高品质满足农村地区消费者实际需求**才是硬道理"＝③的**话题上位概括** ✓ /   A"要深入调研农村消费群体"——后文没有"调研"；C"要统筹兼顾，破解难题，激发企业**积极性**"——后文没有"破解难题"；D"充分发挥乡村消费市场的重要作用"——话题不搭。 |

## 三、语句填空 · 思维提升③④ 话题可能不完整 / 文言文选项
> **思维提升③：单看横线处，是不是必然有完整的核心话题？** /
> **不一定。**横线常常**没有主语、没有完整主谓**——因为它**承接了上文的话题**。此时**不能要求"横线本身话题完整"**，要看**它和上下文是否连贯**。 /
> **动作：**把横线代入上下文读一遍——**能顺畅接上就是对的**，不必要求它自身"像个完整句子"。
> **思维提升④：文言文相关的语句填空** /
> ① **出题人的难度控制**——不会让四个选项都很难理解； /
> ② 注意**衔接紧密的语句，可能起到解释作用**（后句在给前句做注解）。
| 例题 | 答案 | 结构 · 考点 |
|---|---|---|
| 例5 / 2022 国家 / 文化遗产 | D | ①依托数字文化开发是焕发新活力的重要手段　②但科技应用**应有边界**，即____　③**一旦两者冲突，理应遵循"保护优先"原则**　④打造沉浸式场景…其目的无可非议…须慎重。 /   D"**不能对资源本身及其价值造成破坏或产生不良影响**"＝③"保护优先原则"正是对它的**解释** ✓ /   B"要把握好**真实性和娱乐性**之间的尺度"——后文从未出现"真实性""娱乐性"这一对 ✗ |
| 例6 / 2024 国考 / 良法与立法 | A | ①良法是善治的前提（"良法"很重要）　②____　③**发挥好人大及其常委会在立法工作中的主导作用**，坚持尊重客观规律、为了人民依靠人民、严格依照法定权限程序，推进科学立法民主立法依法立法。 /   A"要抓住**提高立法质量**这个关键"＝③整段都是"如何提高立法质量" ✓ /   B"人大要统筹运用**法定监督方式**"——③讲的是"立法"不是"监督"；C"**法律体系**须与时俱进"——③不在谈体系；D"治国理政要保障人民当家作主"——话题过大 ✗ |
| 例7 / 2023 国考 / 人类命运共同体 / **（文言文）** | C（推断） | ①构建人类命运共同体是各国人民前途所在　②____　③**只有各国行天下之大道，和睦相处、合作共赢，繁荣才能持久，安全才有保障**。 /   C"**万物并育而不相害，道并行而不相悖**"（万物互不妨害，各自规律互不冲突）＝③"和睦相处、合作共赢"＋"繁荣才持久"的**文言对应** ✓ /   A"河海不择细流，故能就其深"（容纳、包容）；B"**大道之行也，天下为公**"（"天下为公"＝为公，后文讲的是各国**合作**不是"为公"）；D"芳林新叶催陈叶，流水前波让后波"（新事物代替旧事物，与文段无关）。 /   ※ 本题 PPT 未标答案，此为按逻辑推断，建议对照原课件核对。 |
