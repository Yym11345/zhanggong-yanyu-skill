# 行测言语理解解题大脑 · zhanggong skill

> 「整个言语就考一个半题型：中心理解加选词填空的词语辨析。」
> 「言语学习的一条主线，就是从不确定当中去寻找确定性。」

把名师张弓《言语十二箭》的方法体系，做成**任何 AI Agent 都能装上**的 Skill。
贴一道言语题进去，它会按张弓的思维把重点找出来、把干扰项逐条拆掉、把答案讲成你能迁移的方法。

---

## 这是什么

一个**解题教练** Skill，不是资料包。它内含：

| 层 | 内容 | 体量 |
|---|---|---|
| 方法论 | 七种句间关系 · 11 种句子功能 · 主题词三法 · 干扰项三类型 · 对策「内容＞形式」 | 18 个知识文件 |
| 实证库 | 142 道真题逐题取材判定（含反例边界区） | 已解析 |
| 示范 | 15 道完整解析链（操作顺序示范） | 已解析 |
| 练习 | 12 套作业共 96 题，带参考答案 | 可练 |
| 风格 | 张弓讲课腔原话库（断言／反问／比喻／诊断） | 语气 |
| 资产 | 42 页 A4 可打印《中心理解_方法速记卡》 | 可打印 |

## 支持的题型

中心理解（主旨／意图／标题）｜ 细节判断 ｜ 语句填空 ｜ 接语选择（后文推断）｜ 语句排序 ｜ 逻辑填空（选词填空）

## 核心方法（5 副镜片）

1. **句间关系决定论** —— 文段的重点取决于句子和句子的关系，不取决于单句内容
2. **内容大于标志** —— 标志词只是拐杖，关系的本质取决于内容
3. **主题词信仰** —— 正确答案必含主题词；无主题词 ＝ 错误选项
4. **确定性优先论** —— 意思的正确性是 100% 确定的；剩下的靠对比择优
5. **出题人思维** —— 带着预设去排除，预判干扰项的构造方式

## 输出长什么样

默认 **三步走**（考场 60 秒流）：

```
第一步 · 寻找重点    逐句标功能 → 定位重点句 → 提炼主题词
第二步 · 同义替换    正确项与重点句的对应关系
第三步 · 排除干扰项  A/B/C/D 各写：取材句 → 类型①/②/③ → 理由
```

需要复盘时可升级 **五步完整拆解**（句级标注 → 重点定位 → 主题词提炼 → 选项逐项判定 → 结论迁移）。

**关键约束**：每个错误选项都必须写清「取自文段第几句」和「属于哪一类错法」。这是它和"只报答案"的分界线。

## 安装

### 一键脚本（推荐）

**Linux / macOS**

```bash
curl -fsSL https://raw.githubusercontent.com/YOUR_USER/zhanggong-skill/main/install.sh | bash
```

**Windows（PowerShell）**

```powershell
irm https://raw.githubusercontent.com/YOUR_USER/zhanggong-skill/main/install.ps1 | iex
```

### 手动安装（通用）

把整个目录放到目标 agent 的 skills 目录下即可：

| 平台 | 安装路径 |
|---|---|
| **WorkBuddy** | `~/.workbuddy/skills/zhanggong/` |
| **Claude Code** | `~/.claude/skills/zhanggong/` 或项目内 `.claude/skills/zhanggong/` |
| **ChatGPT**（自定义 GPT / Code Interpreter） | 上传 `SKILL.md` + `references/` 为 Knowledge |
| **豆包（Doubao）** | 智能体开发平台 → 知识库上传 `SKILL.md` + `references/` |
| **ZCode / Cursor / Windsurf / Cline** | 项目内 `.cursor/rules/`、`.windsurf/rules/`、`.clinerules/` |
| **Hermes / 通用 Agent** | `~/.hermes/skills/zhanggong/` |

安装完成后，把 `SKILL.md` 的内容设为系统提示词，或让 agent 直接读取该目录。

## 速记卡（独立资产）

`assets/中心理解_方法速记卡.html` 是 42 页 A4 双层架构的可打印卡片（考场速查层 ＋ 按题型聚类正文）。
浏览器打开后直接打印即可，选「A4、边距 10-11mm、背景图形开启」。

修改卡片后必须跑一遍：

```bash
python scripts/extract_card.py    # 刷新 references
python scripts/repaginate.py      # 重排分页 + 校验 PDF 页数 == HTML 页数
python scripts/verify_card.py     # 答案表抽取 + 结构校验
```

## 诚实边界

- 本 Skill 只覆盖**行测言语理解与表达**，不适用于判断推理／资料分析／数量关系。
- 不臆造真题年份、来源与答案；信息不足时先问用户补全，**不脑补题干**。
- 方法论覆盖课件体系主干；个别冷门题型变体可能需要人工判断。
- 速记卡是**独立资产**，本 skill 的任务是**用它解题**；只有明确要增补卡片时才走卡片维护流程。
